# Di41og

Di41og is a local-first conversation copilot for iPhone and iPad. Its iPad app can also run on Apple silicon Macs.

## Documents

- [Privacy policy](privacy.md)
- [Support](support.md)

## App Summary

- Prepare a planned conversation or start an ad hoc conversation with optional context and goals.
- Transcribe English and German on device and follow changing topics.
- Use optional meeting, practice, media-listening, or casual-talk templates and participant-based duration guidance.
- Follow agenda time slots, review source-linked interpretations, and keep useful notes.
- Estimate up to four voices locally, with names assigned by you.
- Correct word-range voice labels while keeping the original transcript.
- Search imported PDF/text/CV material locally and review cited answer-assist quotations.
- Review calendar drafts before saving; opt into generic preparation reminders, Shortcuts and a private status-only Live Activity.
- Keep records local by default, or explicitly choose encrypted user-folder conversation sync.
- Choose on-device final summaries by default; optionally allow a configured Ollama server to process final-summary text.
- On a compatible Mac, pair a separate audio companion for selected app/display audio. Pairing alone does not start capture, and no audio file is created.

The interface is English; speech selection supports English and German. On-device AI guidance requires compatible hardware and Apple Intelligence availability. Private Cloud Compute integration is prepared but disabled in the current build; it requires Apple's managed entitlement and a configured rebuild. Transcripts, speaker labels and generated suggestions need review. The [privacy policy](privacy.md) explains each optional data flow.
