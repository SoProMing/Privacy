# KVMHub Support

For support, use the [2hands contact page](https://www8.2hands.de/contact/).

## Privacy

Read the [KVMHub Privacy Policy]({{ "/apps/kvmhub/privacy/" | relative_url }})
for information about app data handling.

## Before Contacting Support

Please include:

- The KVMHub version.
- The operating-system version of each computer involved.
- Whether each computer was acting as a controller or receiver.
- The peer platform: macOS, Windows, or Linux.
- A short description of what happened and the steps that reproduce it.

Do not include pairing codes, private keys, machine names, peer identifiers,
private logs, or screenshots containing sensitive information in public GitHub
issues or pull requests.
